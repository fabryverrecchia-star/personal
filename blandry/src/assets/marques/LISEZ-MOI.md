# Logos des marques et fournisseurs

Déposez ici les logos officiels (SVG de préférence, sinon PNG transparent), nommés ainsi :

- caparol.svg
- tollens.svg
- gedimat.svg
- bigmat.svg

Tant qu'un logo est absent, le nom de la marque s'affiche en texte dans le bandeau.
Pour ajouter une marque : compléter la liste `marques` dans src/data/site.ts.
