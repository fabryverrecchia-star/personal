# La bustarella digitale — mise en ligne

1. Créez un dossier, par exemple **`bustarella`**, à côté de `mariage` sur 18h22.com.
2. Envoyez-y **le contenu** de ce dossier (`index.html`, `admin.php`, `api/`, `assets/`, `storage/`, et le fichier caché `.htaccess`).
3. Droits du dossier `bustarella/storage` : **755** (ou 775).
4. Dans `bustarella/api/config.php`, écrivez votre mot de passe :
   `'admin_password' => 'votre-mot-de-passe',`

- Lien à envoyer à Lindsey et Andrea : **https://18h22.com/bustarella/**
- Votre espace privé (IBAN + réponses du quiz) : **https://18h22.com/bustarella/admin.php**

Toujours en **https://**. Une fois le virement fait, vous pouvez supprimer l’entrée IBAN depuis l’espace privé.
