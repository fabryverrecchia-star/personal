# Fonts

Déposer ici les fichiers de police du portfolio :

- `EBGaramond-Italic-VariableFont_wght.ttf` (police principale)
- les autres polices (formats acceptés : `.ttf`, `.otf`, `.woff`, `.woff2`)

Elles seront converties en `.woff2` et sous-échantillonnées (subset) pour de meilleures performances.
