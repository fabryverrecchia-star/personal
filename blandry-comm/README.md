# Communication Benjamin Landry

Campagnes Meta Ads, supports print et web.

- `templates/creas.html` : visuels publicitaires et réseaux (1080 × 1920, 1080 × 1080, 1080 × 1350, couverture, profil)
- `templates/print.html` : carte de visite, flyer A5, bâche 120 × 80 (fonds perdus inclus)
- `scripts/render.mjs` : génère `livrables/` (PNG et PDF) — `node scripts/render.mjs`
- `page/` : page de présentation des campagnes
- `livrables/textes-meta-ads.txt` : textes à copier dans le Gestionnaire de publicités
